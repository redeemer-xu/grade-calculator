# Grade Calculator

**Name:** Redeemer B. Aparece

**Section:** IT3R4

## Description
A simple command-line program that computes the average of your subject grades and tells you if you passed.

## How to Run
1. Install Python 3.
2. Open a terminal in this folder.
3. Run:

```
python3 grade_calculator.py
```

4. Enter the number of subjects, then each grade.
